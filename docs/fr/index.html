Guide de Configuration Détaillé

Suivez ces étapes complètes pour configurer des fonds d'écran dynamiques sur votre appareil.

1

Télécharger le Fichier de Fond d'Écran Animé

Visitez la bibliothèque de fonds d'écran sur mwallx.com sur votre ordinateur ou appareil. Parcourez la collection et téléchargez le fichier de fond d'écran animé au format .tendies de votre choix.

2

Obtenir l'Outil Nugget

Téléchargez et ouvrez la dernière version de Nugget depuis le répertoire GitHub officiel de Nugget. Vous aurez besoin d'un ordinateur macOS ou Windows pour exécuter cet utilitaire de bureau.

3

Importer et Injecter les Réglages

Connectez votre iPhone ou iPad à votre ordinateur. Dans Nugget, recherchez pour importer votre fichier .tendies téléchargé. Suivez les instructions de Nugget pour injecter et appliquer la configuration du fond d'écran sur votre appareil.

4

Activer le Fond d'Écran Animé

Sur votre appareil iOS / iPadOS, accédez à Réglages -> Fond d'écran. Sélectionnez le fond d'écran animé nouvellement importé et activez l'effet dynamique. Maintenez le doigt appuyé sur l'écran de verrouillage ou testez les mouvements sur l'écran d'accueil pour vérifier les animations.

Besoin de notes de version ou de détails de configuration : Ouvrir le répertoire GitHub de Nugget
