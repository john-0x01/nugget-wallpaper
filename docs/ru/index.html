Подробное Руководство

Выполните эти комплексные шаги для настройки динамических обоев на вашем устройстве.

1

Скачайте Файл Живых Обоев

Посетите библиотеку обоев на сайте mwallx.com со своего компьютера или устройства. Просмотрите коллекцию и скачайте нужный файл в формате .tendies.

2

Скачайте Утилиту Nugget

Скачайте и запустите последнюю версию Nugget из официального репозитория Nugget на GitHub. Для запуска этой настольной утилиты вам понадобится компьютер с macOS или Windows.

3

Импортируйте и Примените Настройки

Подключите ваш iPhone или iPad к компьютеру. В Nugget выберите скачанный файл .tendies для импорта. Следуйте инструкциям утилиты для применения настроек обоев на устройстве.

4

Активируйте Живые Обои

На устройстве iOS / iPadOS перейдите в Настройки -> Обои. Выберите импортированные обои и включите живой эффект. Проверьте анимацию долгим нажатием на экране блокировки.

Нужны примечания к выпуску или детали настройки: Открыть репозиторий Nugget на GitHub
