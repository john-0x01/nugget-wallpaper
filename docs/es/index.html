Guía de Configuración Detallada

Sigue estos pasos completos para configurar fondos dinámicos en tu dispositivo.

1

Descarga el Archivo de Fondo de Pantalla Animado

Visita la biblioteca de fondos de pantalla en mwallx.com en tu ordenador o dispositivo. Explora la colección y descarga el archivo de fondo de pantalla animado en formato .tendies de tu elección.

2

Obtén la Herramienta Nugget

Descarga y abre la última versión de Nugget desde el repositorio oficial de Nugget en GitHub. Necesitarás un ordenador macOS o Windows para ejecutar esta utilidad de escritorio.

3

Importa e Inyecta los Ajustes

Conecta tu iPhone o iPad al ordenador. En Nugget, busca para importar tu archivo .tendies descargado. Sigue las instrucciones de Nugget para inyectar y aplicar el payload de configuración del fondo de pantalla en tu dispositivo.

4

Activa el Fondo de Pantalla Animado

En tu dispositivo iOS / iPadOS, ve a Ajustes -> Fondo de pantalla. Selecciona el fondo de pantalla animado recién importado y activa el efecto dinámico. Mantén presionado en la pantalla de bloqueo o comprueba los movimientos en la pantalla de inicio para verificar las animaciones.

Necesitas notas de lanzamiento o detalles de configuración: Abrir el repositorio de Nugget en GitHub
