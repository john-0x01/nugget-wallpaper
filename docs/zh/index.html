详细安装指南

按照以下详尽步骤在您的设备上配置动态壁纸。

1

下载动态壁纸文件

在电脑或设备上访问壁纸库 mwallx.com。浏览合集并下载您喜欢的 .tendies 格式动态壁纸文件。

2

获取 Nugget 工具

从官方 Nugget GitHub 仓库下载并打开最新版本的 Nugget。您需要一台 macOS 或 Windows 电脑来运行该桌面工具。

3

导入并写入设置

将您的 iPhone 或 iPad 连接到电脑。在 Nugget 中，导入您下载的 .tendies 文件。按照 Nugget 的说明将壁纸配置载荷写入您的设备。

4

启用动态壁纸

在您的 iOS / iPadOS 设备上，前往设置 -> 壁纸。选择新导入的动态壁纸并启用动态效果。测试锁定屏幕长按或主屏幕动效以验证效果。

需要发布日志或设置细节： 打开 Nugget GitHub 仓库
