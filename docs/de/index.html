Detaillierte Einrichtungsanleitung

Befolgen Sie diese umfassenden Schritte, um dynamische Hintergrundbilder auf Ihrem Gerät zu konfigurieren.

1

Hintergrunddatei herunterladen

Besuchen Sie die Hintergrund-Bibliothek unter mwallx.com auf Ihrem Computer oder Gerät. Durchsuchen Sie die Sammlung und laden Sie die gewünschte .tendies-Datei herunter.

2

Nugget-Tool herunterladen

Laden Sie die neueste Version von Nugget aus dem offiziellen Nugget-GitHub-Repository herunter. Sie benötigen einen macOS- oder Windows-Computer, um dieses Desktop-Dienstprogramm auszuführen.

3

Einstellungen importieren und übertragen

Schließen Sie Ihr iPhone oder iPad an Ihren Computer an. Suchen Sie in Nugget nach der heruntergeladenen .tendies-Datei, um sie zu importieren. Befolgen Sie die Anweisungen von Nugget, um die Hintergrundkonfiguration auf Ihr Gerät zu übertragen.

4

Live-Hintergrund aktivieren

Navigieren Sie auf Ihrem iOS- / iPadOS-Gerät zu Einstellungen -> Hintergrundbild. Wählen Sie das neu importierte Hintergrundbild aus und aktivieren Sie den Live-Effekt. Halten Sie den Sperrbildschirm gedrückt, um die Animationen zu überprüfen.
