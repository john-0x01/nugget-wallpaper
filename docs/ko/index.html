커스텀 움직이는 배경화면 적용

Nugget Wallpaper를 사용하면 프리미엄 움직이는 배경화면을 iPhone 및 iPad로 가져올 수 있습니다. 지금 .tendies 아셋을 다운로드하고 잠금 화면을 맞춤 설정하세요.

배경화면 라이브러리 열기 Nugget 받기

이 설정이 작동하는 이유

  • 안전한 일상 사용을 위한 탈옥 없는 방법.
  • iPhone 및 iPad 워크플로우 모두에 맞춘 설계.
  • 고품질의 움직이는 배경화면 리소스를 제공하는 외부 라이브러리.
  • 투명한 업데이트가 제공되는 오픈 소스 프로젝트.

움직이는 배경화면

공식 외부 라이브러리에서 엄선된 배경화면을 둘러보세요.

상세 설정 가이드

기기에서 동적 배경화면을 설정하려면 다음의 포괄적인 단계를 따르세요.

1

움직이는 배경화면 파일 다운로드

컴퓨터나 기기에서 배경화면 라이브러리 mwallx.com에 접속합니다. 컬렉션을 둘러보고 원하는 .tendies 형식의 배경화면 파일을 다운로드합니다.

2

Nugget 도구 구하기

공식 Nugget GitHub 리포지토리에서 최신 릴리스의 Nugget을 다운로드하여 엽니다. 이 데스크톱 유틸리티를 실행하려면 macOS 또는 Windows 컴퓨터가 필요합니다.

3

가져오기 및 설정 주입

iPhone 또는 iPad를 컴퓨터에 연결합니다. Nugget에서 다운로드한 .tendies 파일을 선택하여 가져옵니다. Nugget의 지침에 따라 기기에 배경화면 설정 페이로드를 주입하고 적용합니다.

4

움직이는 배경화면 활성화

iOS / iPadOS 기기에서 설정 -> 배경화면으로 이동합니다. 새로 가져온 움직이는 배경화면을 선택하고 라이브 효과를 활성화합니다. 잠금 화면 길게 누르기 또는 홈 화면 움직임을 테스트하여 애니메이션을 확인합니다.

릴리스 노트 또는 설정 세부 정보가 필요한 경우: Nugget GitHub 리포지토리 열기

자주 묻는 질문

Nugget 및 움직이는 배경화면에 대해 궁금한 점이 있으신가요? 여기서 답변을 찾아보세요.

아니요, iPhone이나 iPad를 탈옥할 필요가 없습니다. Nugget Wallpaper는 루트 권한 없이 시스템 수준 설정을 활용하는 안전한 무탈옥 맞춤 설정 워크플로우를 통해 작동합니다.

호환성은 Nugget 도구에 의해 결정됩니다. Nugget은 특정 기기 및 SparseRestore 익스플로잇 창에 따라 iOS 17.0부터 iOS 18.0까지 지원합니다. 지원되는 펌웨어 버전에 대한 최신 업데이트는 공식 Nugget GitHub 페이지를 확인하세요.

예, 외부 라이브러리에서 무료로 애니메이션 배경화면을 둘러보고 다운로드하여 Apple 기기로 가져올 수 있습니다.

.tendies 파일은 Nugget이 라이브 배경화면 데이터 매개변수를 Apple 기기에 기록하기 위해 사용하는 맞춤형 애니메이션 구성 컨테이너입니다. 원본 비디오 루프 아셋과 시스템 경로가 함께 패키징되어 있습니다.
