Panduan Pengaturan Detail

Ikuti langkah-langkah komprehensif ini untuk mengonfigurasi wallpaper dinamis di perangkat Anda.

1

Unduh File Wallpaper Bergerak

Kunjungi perpustakaan wallpaper di mwallx.com di komputer atau perangkat Anda. Telusuri koleksi dan unduh file format wallpaper bergerak .tendies pilihan Anda.

2

Dapatkan Alat Nugget

Unduh dan buka rilis terbaru Nugget dari repositori GitHub resmi Nugget. Anda memerlukan komputer macOS atau Windows untuk menjalankan utilitas desktop ini.

3

Impor dan Injeksikan Pengaturan

Hubungkan iPhone atau iPad Anda ke komputer. Di Nugget, cari untuk mengimpor file .tendies yang diunduh. Ikuti instruksi Nugget untuk menginjeksikan payload konfigurasi wallpaper ke perangkat Anda.

4

Aktifkan Wallpaper Bergerak

Di perangkat iOS / iPadOS Anda, buka Pengaturan -> Wallpaper. Pilih wallpaper bergerak yang baru diimpor dan aktifkan efek live. Uji tekan lama layar kunci atau gerakan layar utama untuk memverifikasi animasi.

Pertanyaan Umum

Punya pertanyaan tentang Nugget dan wallpaper bergerak? Temukan jawabannya di sini.

Tidak, Anda tidak perlu melakukan jailbreak pada iPhone atau iPad Anda. Nugget Wallpaper berfungsi melalui alur kerja kustomisasi aman tanpa jailbreak, memanfaatkan konfigurasi tingkat sistem tanpa izin root.

Kompatibilitas ditentukan oleh alat Nugget. Nugget mendukung iOS 17.0 hingga iOS 18.0 tergantung pada perangkat tertentu dan celah SparseRestore. Silakan periksa halaman GitHub resmi Nugget untuk pembaruan terbaru mengenai versi firmware yang didukung.

Ya, Anda dapat menelusuri dan mengunduh wallpaper animasi gratis dari perpustakaan eksternal lalu mengimpornya ke perangkat Apple Anda.

File .tendies adalah wadah konfigurasi animasi kustom yang digunakan oleh Nugget untuk menulis parameter data wallpaper bergerak ke perangkat Apple. Ini mengemas aset loop video mentah dan jalur sistem bersama-sama.
